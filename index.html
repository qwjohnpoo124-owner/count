第一階段:描述統計

W2 四大變數(測量尺度)

由低到高,「提供的訊息」越來越多(1951 年 Stevens 提出):

名義 次序 等距 比例
能分類 ✔ ✔ ✔ ✔
能排大小順序 ✘ ✔ ✔ ✔
能加減(差距相等) ✘ ✘ ✔ ✔
能乘除 ✘ ✘ ✘ ✔
有絕對零點 ✘ ✘ ✘ ✔
例子 性別、宗教、血型、學號、背號 名次、等第、教育程度、態度量表 溫度、智商、測驗成績 身高、體重、年齡、薪資、面積
  • 名義:只有「次數」有意義(眾數可用),各類別互斥且完整。
  • 次序:能排序,但「第一名和第二名差多少」不知道,所以不能做四則運算。
  • 等距:要有「相等單位」(a>b>c 且 a−b=b−c)。眾數、中位數、平均數都有意義,可加減不可乘除(例如 20℃ 不是 10℃ 的兩倍)。
  • 比例:多了絕對零點,所以可以說「兩倍」。等距和比例都屬於連續變數。
  • 課程的比較表把統計量也分了類:眾數 → 名義;中位數、百分等級、四分位差、積差相關 → 次序;平均數、標準差、標準分數、全距 → 等距。

W3 集中量數(資料的「中心」)

以 12 位學生成績 40,40,50,50,60,60,70,70,70,80,80,90 為例:

量數 做法 例子結果 備註
平均數 全部加總 ÷ 個數 760 ÷ 12 = 63.3 受極端值影響大;分樣本平均與母體平均
中位數 排序後中間那個 N=12 為偶數,取第 6、7 個平均:(60+70)÷2 = 65 N 奇數:第 (N+1)/2 個;偶數:第 N/2 與 N/2+1 個的平均。有 50% 資料高於、50% 低於它
眾數 出現最多次 70(3 人) 適用所有尺度;分配很平均或眾數很多時失去意義

W3 變異量數(資料有多「分散」)

數值越大代表越分散。

量數 意思 重點
全距 R 最大 − 最小 例:身高最大 185、最小 163,R = 22
四分位差 QD Q3 − Q1(中間 50% 資料的範圍) Q1 位置 = (n+1)/4,Q3 位置 = 3(n+1)/4。例:年齡 18~24 七人,Q1=19、Q3=23,QD=4,表示 50% 的人集中在 19–23 歲
平均差 AD 各數離平均的「絕對距離」的平均 離均差總和必為 0,所以要取絕對值才能加總
變異數 離均差平方的平均 📝補充 σ² = Σ(X−μ)²/N
標準差 SD 變異數開根號 必為非負;單位和原資料相同;越大越分散,越小越靠近平均

W3 相對地位量數(你在團體中的位置)

  • 百分等級 PR:有多少 % 的人比你低。
  • 由分數算:PR = (100/N) × 贏過的人數 + (100/N) × ½(加半個等級代表本人)。
  • 由名次算:PR = 100 − (100R − 50)/N。
  • 百分位數 Pk:反過來,第 k 百分位對應的「真實分數」。
  • Z 分數(標準分數):Z = (X − 平均) ÷ 標準差,表示離平均幾個標準差。標準化的過程叫「標準化」。

W4 二項分配 → 常態分配

二項分配(白努力試驗重複 n 次):每次只有「成功(機率 p)/失敗(機率 q=1−p)」。 - 機率:P(X=r) = C(n,r) pʳ qⁿ⁻ʳ,係數可用帕斯卡三角形看。 - 平均數 μ = np,變異數 σ² = npq。 - 例:投手好球機率 0.6,投 100 球 → 期望值 60、變異數 24。 - 例:10 顆球有 2 顆不良品,抽後放回抽 3 次,X=不良品個數,P(X=k)=C(3,k)(0.2)ᵏ(0.8)³⁻ᵏ。 - 二項分配是間斷的;n 越大、p=q=½ 時,它越來越像常態分配(連續)。

常態分配(高斯分配)的特性: 1. 鐘形、左右對稱,平均數 = 中位數 = 眾數,位於最高點。 2. 曲線漸近橫軸但永不相交,總面積 = 1。 3. μ 改變 → 曲線左右平移;σ 改變 → 形狀變胖或變瘦。 4. 經驗法則:μ±1σ 約 68.26%,μ±2σ 約 95.44%,μ±3σ 約 99.74%。 5. 標準常態:Z ~ N(0,1);最高點 y = 0.3989;反曲點在 Z=±1。 6. 📝補充 四分位差在常態下稱機誤:PE = 0.6745σ。

查表例(成果驗收):μ=100、σ=20,某生 137 分 → Z = 1.85 → 面積 0.4678 → 0.5+0.4678 ≈ 96.8%,約 97% 的人不如他。 另一題:平均上 1 個標準差,約在第 84 百分位(50% + 34%)。

偏態與峰度(用動差): | | 係數 | =0 | >0 | <0 | |---|---|---|---|---| | 偏態 g1 | 三級動差,Z 分數三次方的平均 | 對稱(常態) | 正偏(右偏):尾巴在右,低分多,平均數 > 中位數 | 負偏(左偏):高分多,平均數 < 中位數 | | 峰度 g2 | 四級動差,Z 分數四次方的平均 −3 | 常態峰 | 高狹峰(比常態尖瘦,兩端極端值多) | 低闊峰(比常態平寬) |

常態化標準分數(Z 的各種「變身」)——目的是消除小數與負數,讓不同測驗能比較: | 種類 | 公式 | 平均 / 標準差 | |---|---|---| | Z 分數 | (X−μ)/σ | 0 / 1 | | T 分數 | T = 10Z + 50 | 50 / 10 | | 比西(BSS) | 16Z + 100 | 100 / 16 | | 魏氏(WISC) | 15Z + 100 | 100 / 15 | | AGCT | 20Z + 100 | 100 / 20 | | 另有標準 9 分、標準 10 分、C 量表 | | |

  • T 分數例:甲在 A 考場 80 分(平均 78、SD 4)→ T = 50 + 10×(80−78)/4 = 55;乙在 B 考場 90 分(平均 87、SD 9)→ T = 50 + 10×(90−87)/9 = 53.3。甲較高。用途:同一場考試不同考場、評審寬嚴不同時做校正。
  • T 分數的前提是母群體為常態;μ±5σ 內 T 為 0–100,實務上多落在 15–85。
  • 百分等級是次序量尺(永遠為正),標準分數是等距量尺(可為負)。
  • 要換算不同量表,都先轉成 Z 分數。

第二階段:機率

W5 集合、機率、事件、期望值

集合:元素、子集合、空集合(ψ)。 - 運算:聯集 ∪(兩集合所有元素,重複只算一次)、交集 ∩(共同元素)、補集/差集、對稱差集。 - 運算律:交換律、結合律、分配律、冪等律、對偶律(笛摩根)。

機率(0 到 1 的數): - 三種定義:古典(等可能)、統計/頻率(重複試驗的相對次數)、主觀(個人相信程度)。 - P(A) = 事件的樣本點數 ÷ 樣本空間的樣本點數。 - 樣本空間 U:所有可能結果的集合(擲骰子:{1,2,3,4,5,6});其中每個結果是樣本點。 - 事件:樣本空間的任一子集合。必然事件(= 全空間)、不可能事件(= 空集合)。 - 事件分類: - 簡單事件(基本事件):只含 1 個樣本點(擲出 1 點)。 - 複合/複雜事件:含 2 個以上樣本點(擲出奇數 {1,3,5})。

機率公式(講義整理): | 情形 | 公式 | 例子 | |---|---|---| | 互斥(交集為空) | P(A∪B) = P(A)+P(B) | 抽到鬼牌或黑桃 2:¼+¼ = ½ | | 非互斥 | P(A∪B) = P(A)+P(B) − P(A∩B) | 抽到黑桃或 2:½+½−¼ = ¾ | | 獨立事件 | P(A∩B) = P(A)×P(B) | 猜拳連贏 3 次:(⅓)³ = 1/27 | | 相依事件 | P(A∩B) = P(A)×P(B|A) | 3 黑 4 白不放回,連抽 2 白:4/7×3/6 = 2/7 |

期望值 E(X) = ΣPᵢXᵢ(長期重複實驗的平均,也就是母體平均數 μ)。 - 抽獎例:10 球中紅 5 球得 10 元、黃 3 球得 100 元、藍 2 球得 200 元 → E = 5/10×10 + 3/10×100 + 2/10×200 = 75 元。 - 擲 3 枚硬幣,X=反面數:E = 0×⅛+1×⅜+2×⅜+3×⅛ = 1.5。 - 賭局:期望值為正對玩家有利,為負則越玩越虧。 - 變異數:E[(X−μ)²] = σ²,即「無限次重複取樣得到的 s² 平均就是母體變異數」。 - 成果驗收題型:統一發票獎金期望值(特獎 200 萬…六獎 200 元,合計約 1.3024 元/張);若公益團體用 50 元贈品換 50 張未對獎的發票,預期獎金約 65 元 > 50 元,所以划算。

第三階段:推論統計

W6 抽樣

為什麼抽樣?普查耗時、成本高、難蒐集深入資訊、出錯機率也大,所以抽一部分樣本去推估母體。

方法 做法 重點
簡單隨機 每個個體機會均等(抽籤、亂數表) 兩原則:均等機率、獨立。分投返式(還原)與不投返式(不還原)
分層隨機 先把母體分層(例:一~四年級),每層再隨機抽 樣本相同時比簡單隨機更可靠、能比較各層;分層不當就失效。配置法:比例配置(依層大小)、標準差配置(標準差大 → 樣本多)、Neyman 配置(兩者併用)
集群(叢式) 先分成自然集群,抽「整個集群」當樣本 優點:無限母體也能抽、就近調查省時省錢。例:12 個行政區抽 6 區,再抽一條路普查全部住戶
系統 排好順序,每隔 k 個抽 1 個,k = N/n 起點在第一區間內隨機抽。例:母體 5000、抽 50 → k=100,起點抽到 30 → 30, 130, 230, … , 4930

分層 vs 集群:分層是「每一層都抽」,層內相同、層間不同;集群是「抽幾個集群全部調查」。

W6 中央極限定理(整門課最重要的定理之一)

  • 從任何分配的母體,用樣本數 n 夠大(一般 n ≥ 30)重複抽樣,樣本平均數的分配會趨近常態。
  • 樣本平均數的平均數 = 母體平均數 μ。
  • 樣本平均數的標準差(標準誤 SE)= σ/√n,比原來的 σ 小。n 越大越集中。
  • 骰子例:原本是均等分配(非常態),只要擲 2 次取平均,平均數的分配就開始像鐘形。
  • 相關:大數法則——樣本越大,樣本平均越接近母體平均。

W7 抽樣分配與四大分配

  • 抽樣分配:從母體反覆抽樣,每組算出一個統計量(如平均數),這些統計量形成的分配。
  • 名詞:參數(母體的數,如 μ、σ)vs 統計量(樣本的數);估計量(用來估計的公式 X̄)vs 估計值(代入實際資料得到的數)。
  • 抽樣誤差(來自機遇,可用 SE 衡量)vs 非抽樣誤差(調查執行、記錄整理的錯誤)。
  • 影響抽樣分配的因素:母體大小、樣本大小、統計量。

四大分配: | 分配 | 怎麼來 | 形狀特性 | 用途 | |---|---|---|---| | Z(常態) | 樣本平均數轉成 Z | 平均 0、標準差 1,對稱鐘形 | 母體標準差已知,或大樣本 | | t | Z 除以 √(χ²/自由度) | 對稱鐘形、比 Z 扁平、尾巴較厚;df 越大越像常態,df=∞ 時就是常態;df≈30 已很接近;df=1 時 t²=F | 母體標準差未知;比較平均數 | | χ²(卡方) | n 個 Z 平方後加總 | 右偏、值 ≥ 0;平均 = df;可加性:df 相加;df 越大越像常態 | 母體變異數估計/檢定;類別資料(適合度、獨立性、百分比同質性、改變顯著性) | | F | 兩個卡方的比值 | 右偏、值 ≥ 0;有兩個自由度(分子、分母);1/F 也是 F(自由度互換);t² 是 F(1, n−1) | 比較兩母體變異數是否相等 |

  • t 與 Z 比較:t 較扁平、極端值多,所以同一顯著水準下 t 的臨界值較大,較難顯著;n>30 時兩者臨界值接近。
  • 三者(Z、t、F)皆為連續分配,皆源自常態母體。

W8 估計(一)

估計 = 用樣本統計量去推測母體參數。 - 點估計:給一個數字(民調 42%)。 - 區間估計:給一個範圍,這個範圍叫信賴區間,兩端是下、上信賴界限;信賴水準 = 1−α(95%、99%…)。

好的點估計量有四個準則: 1. 不偏性:E(θ̂) = θ(樣本平均數是 μ 的不偏估計量)。 2. 有效性:所有不偏估計量中,變異數最小者。 3. 一致性:n 越大,越接近母數。 4. 充分性:能從樣本中提供最多關於母數的訊息。

虛無假設 H₀ 與對立假設 H₁: - H₀:「沒有差異、沒有影響、沒有關係」(不希望成立的敘述,例:多運動不能減重),我們想推翻它。 - H₁:研究者希望成立的敘述(例:多運動可以減重);推翻 H₀ 就等於支持 H₁。 - 型 I 錯誤(α):H₀ 為真卻拒絕它(又稱顯著水準的風險)。 - 型 II 錯誤(β):H₀ 為假卻沒拒絕它。 - 教育心理常用 α = .05 或 .01。

影響信賴區間寬度的四個因素: | 因素 | 影響 | |---|---| | ① 點估計量的種類 | 只影響區間位置,不影響長度 | | ② 樣本大小 n | n 大 → 區間短(精準) | | ③ 信賴係數 1−α | 1−α 越大 → Z 越大 → 區間越長(精確度反而下降) | | ④ 單尾 / 雙尾 | 雙尾(「是否不同、有無差異」);單尾(「大於、小於、高於、優於」) |

另一個等價說法(誤差大小):樣本越大誤差越小(反比)、母體標準差越大誤差越大(正比)、臨界值越大誤差越大。

區間估計的類型:平均數、變異數、比例(百分比)、相關係數。 1. 平均數:樣本統計量 ± 臨界值 × 標準誤。 - 母體常態、大樣本(n≥30)或 σ 已知 → Z。 - 母體常態、小樣本、σ 未知(用 s 取代)→ t(df = n−1)。 - 例(σ 已知):畢業生薪資 σ=2000、n=25、X̄=19,500 → 19,500 ± 1.96×(2000/√25) = 19,500 ± 784 → 18,716 ~ 20,284。 - 例:WAIS 智商 n=100、X̄=110、σ=15 → 110 ± 1.96×1.5 → 107.06 ~ 112.94。 - 例:投手 30 球,平均 116.5、SD 9.975 → 區間 112.78 ~ 120.22(這裡用的是 t 臨界值 2.045)。 - 例:σ=15、n=25、X̄=110,95% → 110 ± 1.96×3 ≈ 104 ~ 116。 2. 獨立樣本 vs 相依樣本: - 獨立樣本(受試者間設計、等組法):兩組互不影響,組間相關為 0。例:男生智商 vs 女生智商;一班分兩組各用不同教學法。 - 相依樣本(受試者內設計、單一組法):同一批人前後測,或配對。重複量數(同一群人測 K 次)與配對組法(配對成特質相同)。例:同一班期中考 vs 期末考。 - 兩母體平均差用哪個分配? - σ₁、σ₂ 已知 → Z(不論樣本大小)。 - σ 未知、n₁,n₂ ≥ 30 → Z(用 S² 取代 σ²)。 - σ 未知、小樣本 → t:先判斷是否成對;若非成對,再判斷 σ₁²=σ₂² 與否(相等用合併變異數,df=n₁+n₂−2;不等用近似 df)。 - t 檢定三個基本假設:變異數同質性、常態分配、獨立性。 - 📝補充 這一段的考驗公式表在講義是圖片(考驗公式.doc),結構如上。 3. 變異數:樣本變異數服從卡方分配,是右偏非對稱分配,所以不能用「± 誤差」的方式,要用卡方查表。 - 目的①:兩母體平均差檢定前,要先確認變異數同質;②:想了解單一或兩群的分散程度。 - 例:n=20、s²=0.0025、df=19 → σ² 的 95% 信賴區間 0.0014 < σ² < 0.0053(開根號得 σ 約 0.037~0.073)。 - 另有「兩母體變異數比」的區間估計(用 F)。 4. 相關係數:r 的分配不對稱,要先做費雪 Z 轉換,在 Z 上做區間,最後要轉回 r。

W9 估計(二):百分比與樣本數

百分比(比例)區間估計: - 百分比的抽樣分配是二項分配;大樣本時近似常態 → 用 Z。 - 使用條件:n ≥ 30,且 n·p̂、n·(1−p̂) 都 > 5。 - 標準誤 s_p = √(p̂(1−p̂)/n);區間 = p̂ ± Z × s_p。 - 資料類型:連續變數 → 可算平均數;類別變數(二分、多點)→ 只能算次數與百分比。p 與 q 是以每個選項個別為基礎(選或不選),不是整體。 - 例:電話訪問 1000 位成人,40% 贊成離島設賭場 → 95% 區間 37%~43%(抽樣誤差 ±3 個百分點)。 - 例:攔截率 28/40 = 0.7;市占率 16% vs 7%(各 400 人,99%)——為成果驗收題。

樣本大小怎麼決定? - 要看:容許的 α、想要的精確度、對母數的最合理猜測。 - 推估比例所需 n:n = Z²·p(1−p)/e²;p 未知時取最保守的 p=0.5(p(1−p) 最大為 ¼)。 - 例:95%、誤差 ±3% → n ≈ 1067。 - 速記表(95%、p=0.5):±10% → 約 100;±7% → 200;±5% → 400;±3% → 1000;±2% → 2400;±1% → 9600。 - 推估平均數所需 n:📝補充 n = (Zσ/e)²。 - 此推論以簡單隨機抽樣為前提。

期中案例影片:校長要學生畢業發展報告,不能只貼原始資料,要有平均數、次數分配、圖表等統計整理——點出「為什麼要學統計」。

成果驗收答案要點: - 小樣本 t 檢定若母群不常態 → 增加樣本人數(靠中央極限定理)。 - 信賴區間越大 → 信心水準越高(但精確度越低);區間估計與點估計相比,點估計只用單次抽樣,所以不可靠。 - 酒瓶題:廠商宣稱容積 500 cc、變異數 ≤ 3;樣本 25 瓶,平均 495、變異數 5。算出平均數與變異數的 95% 信賴區間後,若不包含宣稱值,就不接受廠商宣稱。

第四階段:關係分析

W10 相關

相關分析看「兩個變數的變動方向與程度」。

  • 線性關係:兩變數像一條直線一起變。直線方程式 Y = bX + a,b 是斜率(X 每變動 1 單位,Y 變動多少)。
  • 五種情形:完全正相關、正相關、零相關、負相關、完全負相關(看散佈圖:左下→右上為正,左上→右下為負;點越貼近直線關係越強;完全相關時點全在同一直線上)。
  • 範圍 −1 ≤ r ≤ +1,沒有單位,可跨樣本比較。
  • 強度(課程判斷):|r| = 0.7–0.99 高度、0.4–0.69 中度、0.1–0.39 低度、<0.1 微弱或無。(另一份複習講義的分法略有不同:0.1–0.3 低、0.5–0.7 中、0.8–1.0 高,考前請以老師說法為準。)
  • 相關係數代表的是「緊密程度」,不是斜率。
  • r = +0.85 和 r = −0.85 關係一樣密切,只是方向不同;不能說正相關大於負相關。
  • 相關不等於因果,原因:①有第三共同因素 ②可逆(誰是因誰是果) ③只是間接關係。
  • r 要經 t 檢定才知道有沒有統計意義,df = N − 2(H₀:ρ = 0)。樣本很小時高 r 也可能是機遇;樣本很大時小 r 也不能忽視。
  • r = 0 有兩種意義:零相關,或是曲線相關。
  • 皮爾遜積差相關:兩變數都是等距/比例變數;r = Σ(Zx·Zy)/N(Z 分數乘積的平均)。
  • 點二系列相關 r_pb:一個變數是二分(男/女)、一個是連續;二分變數視為 0/1 時,算出來就等於 Pearson r;p、q 越接近 0.5,r_pb 才可能接近 1。
  • 變異數 vs 共變數:變異數 = 離均差平方和 ÷ N(自己乘自己),描述一個變數的分散;共變數 = 離均差交乘積和 ÷ N(兩變數交乘),描述一起變的程度;r = 共變數 ÷ (SDx·SDy);共變數為正/負/0,r 就為正/負/0。

W11 簡單直線迴歸

  • 相關看「有沒有關係」,迴歸用 X 預測 Y。X 叫預測變項(自變項),Y 叫效標變項(依變項)。
  • 兩變項要有顯著相關才能預測,無關聯的兩變項無法預測。
  • 迴歸分類:一個自變數 = 簡單迴歸;多個自變數 = 複迴歸(多元迴歸)。
  • 最小平方法:找一條直線使各點到直線的垂直距離平方和最小,這條線叫最適合線 / 迴歸線。
  • 三種迴歸方程式: | 資料形式 | 方程式 | 備註 | |---|---|---| | 原始分數 | Ŷ = a + bX | a 截距、b 斜率;實務預測用 | | 離均差分數 | ŷ = b·x | 原點移到平均數,截距消失 | | 標準分數 | Ẑy = β·Zx | β 為標準化迴歸係數;多個預測變項要比較誰重要,要用它(單位不同,不能比原始 b) |
  • 四個基本假設:①等分散性(變異數同質;不論 X 多少,估計標準誤都相同)②依變項為常態分配 ③預測關係是直線 ④不同 X 下的 Y 互相獨立。
  • 迴歸分析的用途:描述(節目製作費 vs 收視率)、控制(控制價格以控制需求量)、預測。
  • 課程活動:「統計網路學習館」(estat.ncku.edu.tw)動態線性迴歸,觀察新增資料點時迴歸線的變化。

W12 多元迴歸與逐步迴歸

變異的拆解(SS 公式): | 符號 | 意思 | 公式 | 別名 | |---|---|---|---| | SSt | 總變異(只猜平均數 Ȳ 的誤差) | Σ(Y − Ȳ)² | 總離均差平方和 | | SSreg | 被迴歸解釋的變異 | Σ(Ŷ − Ȳ)² | 迴歸離差平方和、被解釋變異 | | SSres | 殘差(預測仍猜錯的部分) | Σ(Y − Ŷ)² | 殘差平方和、未被解釋變異 |

  • SSt = SSreg + SSres;R² = SSreg / SSt(決定係數,預測變項解釋了多少 % 的變異)。
  • 迴歸係數是令 SSres 最小求出來的。

多元(複)迴歸:預測變項 ≥ 2 個,Ŷ = a + b₁X₁ + b₂X₂ + … - 多元相關 R = Y 與預測值 Ŷ 的相關。Ŷ 越接近 Y,預測越準。 - 解決的問題:能否找出線性組合說明關係?關係強度?是否顯著?哪些預測變項最重要、能否減少變項數? - b₁ 的意思:固定 X₂ 時,X₁ 對 Y 的斜率。 - 計算實例:Y=大學入學考、X₁=高中學業成績、X₂=智力測驗。r_y1=.643、r_y2=.768、r_12=.598 → 標準化 β₁=.286、β₂=.597(智力測驗比學業成績重要);R²=.6424(解釋 64.24%)、R=.8015。轉回原始分數:Ŷ = 0.391X₁ + 1.061X₂ − 2.140;某生 X₁=14、X₂=9 → Ŷ = 12.88。 - 注意:原始 b 不能直接比大小(單位不同),不能因 1.061 > 0.391 就說 X₂ 較有預測力;要比重要性請看標準化 β。 - 估計標準誤:SEest = √(SSres/df) = √MS_res。例:SS_res=33.4711、df=7、MS=4.7816 → SEest ≈ 2.19;預測值 95% 信賴區間 = 12.88 ± 2.365 × SEest(t 的 df=7),約 7.70 ~ 18.06。

選預測變項的方法: - 同時迴歸:所有預測變項一起投入,只估係數,不負責篩選。 - 逐步迴歸:從許多候選變項中挑出少數有預測力的。 - 順向選擇:每次選與 Y 相關最大(後續為偏相關平方最大)的變項進入,看 R² 增加多少。 - 逐步法 = 順向選擇的改良:每步一個進入,但已進入的變項會被重新檢驗,若因新變項進來而不再顯著,會被剔除。 - 用途:選擇/剔除變項、評估變項重要性。 - SPSS 預設標準:進入 F 顯著性機率 ≤ .05;移除 ≥ .10。

SPSS 操作要點: - 虛擬變數:間斷(類別)變項要轉成 0/1 才能投入迴歸;虛擬變數個數 = 水準數 − 1。 - 二分(性別):1 個(1=女、0=男)。 - 三分(家庭狀況):2 個(單親 1,0;他人照顧 0,1;雙親 0,0)。 - 四分(北中南東):3 個。 - 操作:轉換 → 重新編碼成同一變數;分析 → 迴歸 → 線性;把效標變項放「依變數」、預測變項放「自變數」;選統計量(估計值、模式適合度、共線性診斷)。 - 讀報表:模式摘要(R、R²、調整後 R²、估計標準誤)、ANOVA(P<.01 代表模式顯著)、係數表(B=原始係數、β=標準化係數、各係數的 t 檢定)。 - 講義例:用「性別、壓力懼怕、課堂焦慮、學習信心…」等 11 個預測變項預測「數學成就」。

W13 卡方考驗(χ²)

用途:處理類別資料(名義、次序),比較「觀察次數 O」與「期望次數 E」差多遠。 公式:χ² = Σ (O − E)² / E。差距越大 → χ² 越大 → 越容易落入拒絕區。通常只做單尾(右尾)。 注意事項:只適用類別資料;各格期望次數最好 ≥ 5(至少 80% 的格子 ≥ 5),不夠要合併;可視為無母數統計。

四種卡方考驗: | 考驗 | 問題 | H₀ | 自由度 | |---|---|---|---| | 適合度 | 觀察次數與理論分配是否相符? | O 與 E 無差異 | k − 1 | | 百分比同質性 | J 個群體在某選項的百分比是否相同? | 各群百分比相同 | (I−1)(J−1) | | 獨立性 | 兩個變項是否有關? | 兩變項獨立 | (I−1)(J−1) | | 改變的顯著性 | 同一批人前後測反應有沒有改變?(重複量數) | 前後無顯著改變(A=D) | 1 |

  • 期望次數:適合度用理論機率 × N;列聯表用 (列總和 × 行總和)/總人數;若各格相等就是 N/k。
  • 同質性 vs 獨立性:都用列聯表;同質性事先固定各群人數(邊際固定,J 個群體);獨立性事先只固定總人數(兩個變項都沒固定)。同質性有「設計變項」(群體)與「反應變項」。
  • 範例結果:
  • 同質性:高一 42、高二 46、高三 37 人調查是否讀過武俠小說,「有」的比例 64.3%、73.9%、75.7%,整體 71.2%;χ² = 1.51 < 臨界值 5.991(df=2)→ 接受 H₀,三年級百分比相同。
  • 獨立性:100 位小學生「左右腦型」 × 「左右手利」,χ² = 15.13 > 6.635(α=.01、df=1)→ 拒絕 H₀,兩者有關。
  • 改變:80 位學生學期初/末是否喜歡美術課,檢定結果 A=D(喜歡→不喜歡的人數 ≈ 不喜歡→喜歡的人數)→ 接受 H₀,無顯著改變。📝補充 常見公式 χ² = (A − D)²/(A + D),只看「改變」的人。
  • 適合度(圖書館課外讀物):200 人,財經 55、電腦 25、小說 30、科學 50、傳記 40;期望各 40 → 📝我算出 χ² = 16.25(df=4、臨界值 9.488)→ 拒絕 H₀,喜好因類別而異,仍有 .05 機率犯型 I 錯誤。
  • 加法性:兩個獨立卡方值相加,自由度也相加。
  • 成果驗收答案:公私立 × 社經地位(各格比例相同)→ 無關;兩洗衣粉品牌(56:14 與 24:6 比例相同)→ 品牌與洗淨程度無關,廣告不宜宣稱 X 較好;健美先生(30、15、15,期望各 20)→ χ² = 7.5 > 5.991 → 三種意見人數有顯著差異。

常考觀念陷阱(來自成果驗收題)

  1. 信賴區間越大 → 信心水準越高,但精確度越低。
  2. t 檢定要求母體常態;違反時補救是增加樣本數(中央極限定理)。
  3. 中央極限定理前提不需要母體是常態。
  4. 常態分配:平均 = 中位數 = 眾數;約 0.3% 在 ±3σ 之外,不是「±5σ 外有 1%」(那題的選項是錯的敘述)。
  5. 相關係數看絕對值判斷強弱;不是斜率;不等於因果。
  6. R² = SSreg / SSt。
  7. 虛擬變數個數 = 水準數 − 1。
  8. 卡方的期望次數太小(< 5)要合併或校正。
