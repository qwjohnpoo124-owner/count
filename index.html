第一階段:描述統計

W2 四大變數(測量尺度)

什麼是變數? 依人、事、時、地、物的某種屬性,會產生數值或類別變化的觀察值。分類方式 1951 年由 Stevens 提出,測量尺度由低到高,「提供的訊息」越來越多:

名義 次序 等距 比例
能分類 ✔ ✔ ✔ ✔
能排大小順序 ✘ ✔ ✔ ✔
能加減(差距相等) ✘ ✘ ✔ ✔
能乘除 ✘ ✘ ✘ ✔
有絕對零點 ✘ ✘ ✘ ✔
有意義的集中量數 眾數 眾數、中位數 眾數、中位數、平均數 同左
例子 性別、宗教、血型、國籍、學號、背號、月份 名次、等第、教育程度、百分等級、態度量表 溫度、智商、測驗成績、音量 身高、體重、年齡、薪資、面積、體積

逐項說明:

  • 名義變數(名目、類別變數):用數字或名稱「辨認類別」,類別之間沒有順序與大小。各類別必須互斥(不重疊)且完整(涵蓋所有情況)。只有「次數」有意義。
  • 次序變數(順序變數):除分類外,還能排出大小順序(第 1、2、3 名),但不知道差距(第一與第二名差多少?)。所以不能做四則運算。作文給甲乙丙、態度評定量表都是依據次序變項。
  • 等距變數(區間變數):除上述外,能算出差距大小,有相等單位(a>b>c 且 a−b = b−c),但沒有絕對零點(0℃ 不是「沒有溫度」)。可加減,不可乘除(20℃ 不是 10℃ 的兩倍)。平均數、標準差、積差相關都適用於等距以上資料。
  • 比例變數(比率變數):還有絕對零點(自然原點),可以做加減乘除,能說「某比率等於某比率」(40 公斤是 20 公斤的兩倍)。
  • 等距與比例都屬於連續變數;名義與次序屬於間斷(類別)資料。
  • 課程比較表把統計量分類:眾數 → 名義;中位數、百分等級、四分位差、積差相關 → 次序;平均數、標準差、標準分數、全距 → 等距。

W2 次數分配

意義:把蒐集到的原始資料(混亂的一堆數字)整理成「各數值/各組出現幾次」的表,簡稱次數表。

W3 集中量數(資料的「中心」)

以 12 位學生成績 40,40,50,50,60,60,70,70,70,80,80,90 為例。

① 算術平均數

  • 公式:樣本 X̄ = ΣX / n;母體 μ = ΣX / N。
  • 例:(40+40+50+50+60+60+70+70+70+80+80+90) ÷ 12 = 760 ÷ 12 ≈ 63.3。
  • 性質:每個數都參與計算,所以受極端值影響大;📝 各數的離均差(X − X̄)總和恆為 0。

② 中位數 Mdn:由小到大排列後,最中間的那個數;有 50% 資料高於它、50% 低於它。

  • N 為奇數:第 (N+1)/2 個位置。例:11 個分數 → (11+1)/2 = 第 6 個。
  • N 為偶數:第 N/2 與第 N/2 + 1 兩個數的平均。例:N=12 → 第 6、7 個(60 與 70)→ (60+70)/2 = 65。
  • 不受極端值影響(抗極端值)。

③ 眾數 Mo:出現次數最多的數。例:70 出現 3 次 → 70。

  • 適用所有測量尺度。
  • 限制:分配很平均或有很多眾數時失去意義;不一定最接近中心。

三者關係(📝):對稱分配 平均數 = 中位數 = 眾數;正偏態(右偏)平均數 > 中位數 > 眾數;負偏態相反。

W3 變異量數(資料有多「分散」)

數值越大代表資料越分散。仍用上面 12 位成績,平均 = 63.33。

量數 意思與公式 本例計算
全距 R R = 最大值 − 最小值 90 − 40 = 50。(另例:身高最大 185、最小 163,R = 22)
四分位差 QD QD = Q₃ − Q₁(中間 50% 資料的範圍)。Q₁ 位置 = (n+1)/4,Q₃ 位置 = 3(n+1)/4 例:年齡 18~24 歲七人 → Q₁ 位置 2 → 19;Q₃ 位置 6 → 23;QD = 4 歲
平均差 AD AD = Σ|X − X̄| / n。離均差總和為 0,所以必須取絕對值才能加總 Σ|離均差| = 160 → AD = 160/12 ≈ 13.33 📝
變異數 母體 σ² = Σ(X − μ)² / N;樣本 s² = Σ(X − X̄)² / (n − 1) SS = 2866.67 → σ² ≈ 238.89;s² ≈ 260.61 📝
標準差 SD 變異數開根號:σ = √σ²、s = √s² σ ≈ 15.46;s ≈ 16.14 📝
變異係數 CV(📝) CV = SD ÷ 平均數 × 100%(無單位,可比較不同單位資料的分散程度) 15.46/63.33 ≈ 24.4%

標準差的性質:非負數;與原資料單位相同;越大代表各值離平均越遠。

📝 為什麼樣本變異數除以 n − 1?因為樣本平均數是用同一批資料算的,損失了 1 個自由度,除以 n − 1 才是母體變異數的不偏估計。

W3 相對地位量數(你在團體中的位置)

① 百分等級 PR:一個分數在團體中,「勝過」多少 % 的人。團體被分成 100 等級,PR 只在教育統計用。

  • 由分數算:PR = (100/N)×(贏過的人數) + (100/N)×(½)。最後加「半個等級」代表本人本身。
  • 由名次 R 算:PR = 100 − (100R − 50)/N。
  • 例:12 人中得 90 分者(第 1 名,贏過 11 人):PR = (100/12)×11 + (100/12)×½ = 91.67 + 4.17 ≈ 95.8;用名次算 100 − (100×1 − 50)/12 = 95.8,結果相同。📝

② 百分位數 Pₖ:把資料由小到大排,累積到 k% 的位置所對應的分數。PR 與 Pₖ 是同一件事的兩個方向:PR 是「分數 → 百分比」,Pₖ 是「百分比 → 分數」,Pₖ 是真實存在的分數。

③ Z 分數(標準分數):Z = (X − 平均數) ÷ 標準差,表示離平均有幾個標準差;原始分數轉成 Z 的過程叫「標準化」。

  • 轉換後:平均 = 0、標準差 = 1,單位消失。
  • 例:成績 80 分 → Z = (80 − 63.33)/15.46 ≈ 1.08 📝。
  • Z 分數轉換是直線轉換,個別資料間的相互關係不變;原來不是常態,轉換後也不會變常態。

PR 與 Z 的比較:PR 是「次序量尺」(永遠為正);標準分數是「等距量尺」(可為負)。

W4 二項分配

白努力試驗:只有兩種結果的隨機試驗(成功/失敗、及格/不及格、正面/反面)。令成功機率 p、失敗機率 q = 1 − p,則 p + q = 1。

二項分配 = 重複 n 次獨立白努力試驗中,「成功次數 X」的分配。

  • 機率公式:P(X = r) = C(n, r) · pʳ · qⁿ⁻ʳ,其中 C(n, r) = n!/(r!(n−r)!)。
  • 係數可由帕斯卡三角形得到:(p+q)ⁿ 展開的係數是 1,1 / 1,2,1 / 1,3,3,1 / 1,4,6,4,1 / 1,5,10,10,5,1 …,各項係數和 = 2ⁿ。
  • 例:擲 3 枚硬幣,X = 正面次數:P(0)=1/8、P(1)=3/8、P(2)=3/8、P(3)=1/8。擲 5 枚:1/32, 5/32, 10/32, 10/32, 5/32, 1/32。擲 16 枚得 5 次正面:C(16,5)(½)¹⁶ = 4368/65536。
  • 例(課程):10 球中 2 個不良品,抽後放回抽 3 次,X = 不良品數:P(X=k) = C(3,k)(0.2)ᵏ(0.8)³⁻ᵏ。

平均數與標準差:

  • μ = np;σ² = npq;σ = √(npq)。
  • 例:擲 5 枚硬幣正面:μ = 5×½ = 2.5,σ² = 5×½×½ = 1.25。擲 16 枚:μ = 8,σ² = 4,σ = 2。
  • 例:投手好球機率 p = 0.6,投 n = 100 球 → μ = 60,σ² = 100×0.6×0.4 = 24。
  • 二項分配是間斷的;常態分配是連續的。n 越大,兩者越接近(📝 一般要 np、nq 都 ≥ 5)。

W4 常態分配

怎麼來:當 (p+q)ⁿ 的 n 增加到無限大,且 p = q = ½ 時,二項分配的直方圖趨近一條左右對稱的平滑鐘形曲線,就是常態分配(N.D.);因高斯導出,又稱高斯分配。

特性:

  1. 只適用於連續變項,是連續分配;觀察值範圍從 −∞ 到 +∞。
  2. 鐘形、左右對稱;平均數 = 中位數 = 眾數,都在曲線最高點(曲線中心)。
  3. 曲線兩端向橫軸漸近,但絕不相交;曲線下總面積 = 1。

標準常態分配:把常態分配標準化(μ = 0,σ = 1),記為 Z ~ N(0,1)。

  • Z = (X − μ)/σ;反過來 X = μ + Zσ。
  • 最高點 y = 0.3989(Z = 0);兩個反曲點在 Z = ±1;對稱於 Z = 0。

  1. 先把原始分數轉成 Z。
  2. 查 0 到 z 的面積。
  3. 依題意加減:Z 大於某值 → 0.5 − 面積;Z 小於某正值 → 0.5 + 面積;介於兩點 → 兩面積相減(同側)或相加(異側)。

第二階段:機率

W5 集合

  • 集合:由明確的事物組成的群體,例:A = {足球, 棒球, 網球}。元素:組成集合的每個東西;足球 ∈ A 讀作「屬於 A」。
  • 子集合 C ⊆ A:C 的元素全在 A 中。空集合 ψ:沒有元素(例:今天缺席人數 0)。
  • 聯集 A∪B:兩集合所有元素放在一起,重複只算一次。交集 A∩B:兩集合共同的元素;若 A∩B = ψ 稱互斥(不相交)。
  • 補集 Aᶜ:全集中不屬於 A 的元素;差集 B − A:屬於 B 但不屬於 A;對稱差集:只屬於其中之一者。
  • 運算律:交換律、結合律、分配律、冪等律、對偶律(笛摩根:(A∪B)ᶜ = Aᶜ∩Bᶜ)。
  • 📝 聯集元素個數 = A + B − (A∩B)(重疊區塊不可重複算)。

W5 機率

  • 機率:隨機事件發生的可能性,是 0 到 1 的數(也可用百分比)。P(U) = 1,P(ψ) = 0;📝 P(Aᶜ) = 1 − P(A)。
  • 三種定義:①古典(每種結果可能性相同)②統計/頻率(多次重複試驗中出現的相對頻率,客觀)③主觀(觀察者的相信程度)。
  • 樣本空間 U:一個實驗所有可能結果的集合;每個結果叫樣本點。例:擲骰子 U = {1,2,3,4,5,6};擲 2 枚硬幣 U = {(正,正),(正,反),(反,正),(反,反)}。
  • 事件:樣本空間的任一子集合(含空集合)。若樣本空間有 m 個樣本點,共有 2ᵐ 個事件(每個點「取或不取」)。擲 2 枚硬幣 m = 4 → 16 個事件。
  • 特殊事件:必然事件(= 全集 U,一定發生)、不可能事件(= 空集合,不可能發生)。
  • 計算:P(A) = a / n(a = A 的樣本點數,n = 樣本空間點數)。例:擲 1 枚硬幣得正面 = 1/2。

W5 期望值與變異數

  • 期望值 E(X) = 隨機變數的「代表值」,是長期重複實驗所得的平均數;等於每個結果值 × 它的機率,再全部加總。
  • 間斷型:E(X) = ΣPᵢXᵢ(Pᵢ 是機率);連續型:E(X) = ∫ x·f(x) dx。
  • 它就是母體平均數:E(X) = μ。
  • 例 1(抽獎):紅球 5 個得 10 元、黃球 3 個得 100 元、藍球 2 個得 200 元:E = 0.5×10 + 0.3×100 + 0.2×200 = 75 元。
  • 例 2(擲 3 枚硬幣的反面數):E = 0×⅛ + 1×⅜ + 2×⅜ + 3×⅛ = 1.5。
  • 賭局:期望值為正 → 長期對玩家有利;為負 → 越玩越輸。
  • 變異數:Var(X) = E[(X − μ)²] = Σ Pᵢ(Xᵢ − μ)² = σ²。例:甲 15 元、乙 10 元、丙 5 元,平均 10,離均差平方和 = 25 + 0 + 25 = 50。📝 計算式:Var(X) = E(X²) − μ²。
  • 📝 線性轉換:E(aX + b) = a·E(X) + b;Var(aX + b) = a²·Var(X)。
  • 成果驗收題(公車載客人數):人數 20/30/40/50/60/70/80/90,機率 .05/.1/.1/.1/.25/.25/.1/.05 → 📝 E(X) = 58,Var(X) = 326。每人投幣 15 元,Y = 15X → E(Y) = 870 元,Var(Y) = 15² × 326 = 73,350。
  • 成果驗收題(統一發票):獎金 × 機率:特獎 200 萬×(1/10⁸) = 0.02、頭獎 0.008、二獎 0.0144、三獎 0.036、四獎 0.144、五獎 0.36、六獎 0.72 → 每張期望獎金 ≈ 1.3024 元;50 張預期中獎約 65.12 元 > 50 元贈品 → 公益團體划算;100 張預期中獎約 130.24 元。

第三階段:推論統計

W6 抽樣

基本名詞:母體(想研究的全部對象)、樣本(實際抽出的一部分)、參數 / 母數(描述母體的數,μ、σ)、統計量(描述樣本的數,X̄、s)。「抽樣」= 從母體選取部分元素,用樣本的特徵推知母體。

為什麼要抽樣? 普查 ① 耗時耗力、成本高 ② 無法蒐集較深入詳細的資訊 ③ 出錯的機率反而較大。

抽樣設計要想的事:有哪些機率抽樣方法?有哪些非機率抽樣方法?抽樣要考慮哪些要素?注意:抽樣架構(名單範圍對不對?例:「政大水準高」的比較對象是國內各大學還是歐美大學?)、樣本代表性(代表性有問題會影響外部效度/概化)、樣本大小。

方法 做法 重點與例子
簡單隨機 每個個體被抽到的機會相等(摸彩、亂數表) 兩原則:①均等機率(每個人 1/10 …)②獨立(某人被抽到不影響別人)。分投返式(還原):抽完放回,母體永遠 N 個;不投返式(不還原):抽完不放回,母體剩 N − n
分層隨機 先依特性把母體分 K 層(性別、年級),每層再隨機抽 樣本相同時比簡單隨機更可靠,能比較各層;分層不當就失去代表性。層間主要變數差異最大、層內變異最小才是好分層。配置法:比例配置(依層大小,例:7000 男 3000 女抽 100 人 → 70 男 30 女)、標準差配置(標準差大 = 同質性低 → 樣本多)、Neyman 配置(兩者併用)
集群(叢式、部落) 先把母體分成自然/人為的集群,抽到的整個集群全部調查 優點:使無限母體的隨機抽樣成為可能;就近集中調查,省時省錢。例:12 個行政區隨機抽 6 區,再抽一條路普查所有住戶
系統(間隔) 把母體排序,每隔 k 個抽 1 個 母體或樣本很大時,簡單隨機太費力。步驟:①母體編號排列(戶口名簿、電話簿)②k = N/n ③第一區間 k 個中隨機抽 1 個為起點 ④起點起每隔 k 個抽一個,共 n 個。例:N = 5000、n = 50 → k = 100,起點抽到 30 → 30, 130, 230, …, 4930

分層 vs 集群:分層是「每一層都抽一些」(層內相似、層間不同);集群是「抽幾個集群,集群內全部調查」(集群內部本來就很像母體的縮影)。

W6 中央極限定理(整門課最重要的定理之一)

  • 敘述:從任何分配的母體(平均 μ、變異數 σ²)重複抽取大小 n 的隨機樣本,當 n 夠大(一般 n ≥ 30),樣本平均數 X̄ 的分配趨近常態分配。標準化後 Z = (X̄ − μ)/(σ/√n) 趨近標準常態分配。
  • 三個重點: 1. 樣本平均數的平均數 = μ。 2. 樣本平均數的標準差 = σ/√n,稱為標準誤 SE,比 σ 小(n 越大越集中)。 3. 母體不需要是常態。
  • 骰子例:每面機率 1/6(均等分配,不是常態)。擲兩次取平均 X̄,可能值 1, 1.5, …, 6,機率 1/36, 2/36, 3/36, 4/36, 5/36, 6/36, 5/36, …, 1/36(像一個三角形/鐘形);平均數 3.5(與原本骰子平均數相同);📝 原骰子 σ = √(35/12) ≈ 1.71,n = 2 時標準誤 ≈ 1.71/√2 ≈ 1.21。只要 n = 2 就開始接近常態。
  • 相關:大數法則——樣本越大,樣本平均數越接近母體平均數,觀察次數越多結果越可信。

W7 抽樣分配

  • 抽樣分配:從母體反覆抽樣(每次 n 個),每組算出一個統計量(如 X̄),這無限多個統計量形成的分配;是「多次抽樣的機率分配」。
  • 統計推論的核心:用樣本統計量去推估或檢證母數。
  • 估計量(estimator,用來估計的公式 X̄)vs 估計值(estimate,把實際樣本代入得到的數值 x̄)。
  • 影響抽樣分配的因素:母體大小、樣本大小、樣本統計量(統計量隨抽樣而變,本身是隨機變數)。
  • 抽樣分配的功能:衡量並說明統計推論結果的可靠性。
  • 抽樣誤差 = 樣本統計量與母數的差,來自機遇、抽樣方法、推論方法;估計量的機率分配集中在母數附近 → 抽樣誤差小。非抽樣誤差:調查執行、事後記錄與整理資料時的錯誤。
  • 樣本平均數的抽樣分配:n 夠大(N ≥ 30 或 50)時為常態;平均數 = μ;標準誤 = σ/√n,明顯小於母體的 σ。

W8 估計(一)

估計 = 用機率分配的原理,由樣本統計量推測母體參數(又稱推定、推估)。

兩種估計

  • 點估計:用單一數字估計。例:民調 42% 選民會投給某候選人。
  • 區間估計:給一個區間。區間的長度稱信賴區間(CI);兩端稱區間估計值,左端為下信賴界限,右端為上信賴界限;信賴水準(信賴度、信賴係數)= 1 − α。
  • 1 − α 越大 → 區間越寬,但精確度越低。
  • 📝 正確說法:「用同樣方法重複做很多次,約 95% 的區間會包含 μ」;不是「μ 有 95% 機率落在這個已算出的區間」。

統計量、估計量、估計值:統計量(樣本表徵數,不含未知母數);估計量(用來估計母數的統計量);估計值(代入實際樣本資料得到的值)。

好的點估計量有四個準則

  1. 不偏性:E(θ̂) = θ。樣本平均數是 μ 的不偏估計量;📝 s²(除以 n−1)是 σ² 的不偏估計量。
  2. 有效性:所有不偏估計量中變異數最小者(最有效估計量要同時 E(θ̂) = θ 且 Var(θ̂) 最小)。
  3. 一致性:n 越大,θ̂ 越接近 θ(樣本等於母體時 X̄ = μ)。
  4. 充分性:能從樣本提供被估計母數最多的訊息。

假設檢定的基本概念

  • 虛無假設 H₀:與研究推論相反方向的陳述——「沒有差異、沒有影響、沒有關係」,是「不希望成立」的敘述,先假設它為真,想把它推翻。例:多運動無法減重。
  • 對立假設 H₁:研究者「希望成立」的敘述;不直接驗證,只要推翻 H₀ 就自然支持 H₁。例:多運動可以減重。
  • 型 I 錯誤(α 風險):H₀ 為真,卻拒絕 H₀。α = P(拒絕 H₀ | H₀ 為真),又稱顯著水準。
  • 型 II 錯誤(β 風險):H₀ 為假,卻沒拒絕 H₀(接受 H₀)。β = P(接受 H₀ | H₁ 為真)。
  • 📝 決策矩陣:
實際 H₀ 為真 實際 H₀ 為假
拒絕 H₀ 型 I 錯誤(α) 正確
不拒絕 H₀ 正確 型 II 錯誤(β)
  • 心理與教育統計習慣取 α = .05 或 .01;α 大小取決於犯型 I 錯誤的損失、研究者經驗態度、過去文獻。
  • 📝 假設檢定步驟:①建立 H₀、H₁ ②選檢定統計量(Z/t/χ²/F)③決定 α 並查臨界值 ④計算統計量 ⑤落入拒絕區(臨界區、危險區)→ 拒絕 H₀,否則不拒絕。
  • 單尾 vs 雙尾:雙尾(拒絕區在兩端,各 α/2)適用「異於」「是否不同」「有無差異存在」「是否有關聯」;單尾(右尾或左尾)適用「大於、小於、高於、優於」。

兩母體平均差用哪個分配?

  1. σ₁²、σ₂² 已知 → Z(不論樣本大小)。
  2. σ² 未知,且 n₁ ≥ 30、n₂ ≥ 30 → Z(用 s² 取代 σ²,不需判斷變異數是否相等)。
  3. σ² 未知,小樣本 → t:先判斷是否成對抽樣;若非成對,再判斷 σ₁² = σ₂² 或不等。 - 📝 σ₁² = σ₂²(兩獨立小樣本):用合併變異數 s_p² = [(n₁−1)s₁² + (n₂−1)s₂²]/(n₁+n₂−2),df = n₁ + n₂ − 2。 - 📝 σ₁² ≠ σ₂²:df 用近似公式,取最接近的整數。 - 📝 成對(相依)樣本:算每人差值 d,對 d 做單一樣本 t,df = n − 1。

t 檢定的三個基本假設:①變異數同質性(σ₁² = σ₂²)②常態分配(兩樣本來自的母群為常態)③獨立性(樣本內各數值彼此獨立,群內相關為 0)。

W8 母體變異數的區間估計

為什麼重要?變異數代表分散程度(股票報酬率變異數 = 獲利風險;墊片直徑標準差不得超過某範圍)。目的:① 做兩母體平均差估計/檢定前,要確認變異數同質(σ₁² = σ₂²),否則直接比平均數沒有意義;② 想了解單一母群或兩母群的分散程度。

  • 單一母體 σ²:樣本變異數服從卡方分配(右偏、非對稱),不能用「± 誤差」,要用兩個卡方臨界值: (n−1)s² / χ²_{右} < σ² < (n−1)s² / χ²_{左}(df = n − 1,信賴係數 1 − α)。
  • 例:20 個容器,s² = 0.0025,df = 19,95%:右尾臨界 χ² = 32.85、左尾臨界 χ² = 8.907 → 0.0014 < σ² < 0.0053 → 開根號得 σ 約 0.037 ~ 0.073。
  • 兩母體變異數比(σ₁²/σ₂²):用 F 分配。
  • 📝 酒瓶題:n = 25、X̄ = 495、s² = 5;平均數 95% 區間(t(24, .025) = 2.064)= 495 ± 0.92 → 494.08 ~ 495.92;變異數區間 = 24×5/39.364 ~ 24×5/12.401 = 3.05 ~ 9.68。兩個區間都不含廠商宣稱(平均 500、變異數 ≤ 3)→ 公賣局不接受宣稱。

W9 估計(二):百分比(比例)與相關

百分比區間估計

  • 百分比的抽樣分配是二項分配,大樣本時近似常態,用 Z 公式。
  • 條件:n ≥ 30,且 n·p̂ 與 n·(1−p̂) 都 > 5。
  • 標準誤 s_p = √( p̂(1 − p̂) / n );區間 = p̂ ± Z_{α/2} · s_p。
  • 兩母體比例差 p₁ − p₂:📝 (p̂₁ − p̂₂) ± Z·√( p̂₁q̂₁/n₁ + p̂₂q̂₂/n₂ )。
  • 獨立樣本;相依樣本的百分比差異考驗留到卡方章節。
  • 資料類型:連續變數可算平均數 → 估計平均數;類別變數(二分尺度:是/否;多點尺度:≥ 3 個選項)只能算次數與百分比。計算 p、q 是以每一個選項個別(選或沒選)為基礎,不是整體百分比。

算例

  • 電話訪問 1000 位成人,40% 贊成離島設賭場:s_p = √(0.4×0.6/1000) ≈ 0.0155;誤差 = 1.96×0.0155 ≈ 0.03 → 37% ~ 43%。解讀:在 95% 信心水準下,有 37%~43% 的人贊成;或「40% 贊成,抽樣誤差 ±3 個百分點」。
  • 📝 攔截率:40 顆飛彈攔截 28 顆 → p̂ = 0.7;s_p = √(0.7×0.3/40) = 0.0725;90%(1.645)→ ±0.119 → 0.581 ~ 0.819。
  • 📝 市占率(各 n = 400,99%,Z = 2.576):事件前 p̂ = 0.16 → ±0.047 → 11.3% ~ 20.7%;事件後 p̂ = 0.07 → ±0.033 → 3.7% ~ 10.3%(兩區間不重疊,表示下降顯著)。

相關係數的區間估計:r 的分配(r ≠ 0 時)不對稱,要先做費雪 Z 轉換(📝 z_r = ½ ln[(1+r)/(1−r)],標準誤 = 1/√(n−3)),在 Z 上做 ± 誤差,最後再轉回 r,才是正確答案。

樣本大小 n 怎麼決定?

  • 要看:容許的 α、想要的精確度、對母數最合理的猜測。
  • 估計比例:最大容許誤差 e,則 n = Z²·p(1−p) / e²。
  • p 已知 → 直接代入;
  • p 未知 → ① 二階段抽樣(先抽 n₁ 個用 p̂ 代替 p)② 取 p = 0.5(因 p(1−p) 最大值 = ¼,最保守)。
  • 例:95%、e = 0.03 → n = 1.96² × 0.25 / 0.03² ≈ 1067。
  • 速記表(95%、p = 0.5):±10% → 100;±7% → 200;±5% → 400;±3% → 1000;±2% → 2400;±1% → 9600。
  • 估計平均數:📝 n = (Z·σ / e)²。
  • 以上建立在簡單隨機抽樣;若是集群抽樣等,要另外考量。
  • 系統抽樣的 k ≤ N/n;若 N 未知,先決定 n 再猜 k。

期中案例影片:校長要學生畢業發展報告,不能只貼原始資料,要有平均數、次數分配、圖表等統計整理——點出「為什麼要學統計」。

成果驗收答案要點

  • t 檢定要求母群常態;違反時補救 = 增加樣本人數(中央極限定理)。
  • 信賴區間越大 → 信心水準越高(但精確度越低);點估計只用一次抽樣結果,無法知道是否等於真值。
  • 中央極限定理的前提是「n 夠多」,不需母體常態。

第四階段:關係分析

W10 相關

目的:探討兩變項(X, Y)的變動方向與互動程度。

線性關係:兩變項像一條直線般一起變化;可用最具代表性的直線 Y = bX + a 表示(b = 斜率 = ΔY/ΔX,X 每增加 1 單位 Y 變動的量;a = 截距)。用散佈圖看。

五種情形:完全正相關(點全在一條左下→右上的線上)、正相關、零相關(一橫線、一直線或完全散亂)、負相關、完全負相關(左上→右下)。

相關係數的特質

  • 範圍 −1 ≤ r ≤ +1;沒有單位,可跨樣本比較;正負號代表方向,絕對值代表強度。
  • 強度(課程):|r| = 1 完全;0.7~0.99 高度;0.4~0.69 中度;0.1~0.39 低度;< 0.1 微弱或無。(另一份複習講義:0.1~0.3 低、0.5~0.7 中、0.8~1.0 高,考前以老師說法為準。)
  • r 的大小不與「關係強弱」成正比(📝 r = 0.8 不是 r = 0.4 的兩倍;r 本質接近次序量尺)。
  • r = +0.85 與 r = −0.85 同樣密切,只是方向不同;不能說正相關大於負相關。
  • r = 0 有兩種意義:零(直線)相關,或是曲線相關——只能說「沒有直線相關」。
  • 相關係數代表的是各點貼近直線的緊密程度,不是直線斜率。
  • 相關不等於因果:原因 ① 有第三共同因素 ② 可逆(誰是因誰是果)③ 只是間接關係。要確認因果,需用實驗法(操弄自變項、控制無關變項)。
  • 📝 決定係數 r²:X 能解釋 Y 變異的比例。例:r = 0.2、n = 102 雖達顯著(臨界值 0.195),但 r² = 0.04,只解釋 4%,實務意義微乎其微。樣本很大時小 r 也容易顯著,要同時看實用意義。
  • 📝 團體同質性影響 r:團體異質性高(如小學生智力與成績)r 較大;同質性高(如田徑代表隊、經篩選的大學生)r 會變小,不是因為人數減少,而是因為團體內變異變小。

積差相關係數(皮爾遜 r):兩變數都是等距或比例變數;最常用,由 Karl Pearson 發展。

  • 定義公式:r = Σ(Zx · Zy) / N(兩變項的 Z 分數乘積的平均)。
  • 共變數公式:Cov(X,Y) = Σ(X − X̄)(Y − Ȳ)/N;r = Cov(X,Y) / (Sx · Sy),也寫成 Cov = r·Sx·Sy。共變數為正/負/0,r 也為正/負/0。
  • 計算式(📝):r = SP / √(SSx · SSy)。
  • 變異數 vs 共變數:變異數 = 離均差平方和 ÷ N(同一變項自乘),描述一個變項的分散性;共變數 = 離均差交乘積和 ÷ N(不同變項交乘),描述兩變項共同變化的關聯性。
  • 顯著性檢定:H₀:ρ = 0(母體無相關)。📝 t = r√(N−2) / √(1−r²),df = N − 2。也可以用 r 的臨界值表直接比(依 df、α、單/雙尾)。例:N = 15、r = .54、α = .05 雙尾,臨界值 .514 → .54 > .514 → 達顯著。N 很小時,高 r 也可能是機遇;N 很大時,小 r 也不能忽視。
  • 點二系列相關 r_pb:一個變項是二分(男/女)、一個是連續變項。📝 r_pb = (M_p − M_q)/S · √(pq)(M_p、M_q 為兩組在連續變項上的平均,p、q 為兩組人數比例)。範圍 −1~+1;為正代表二分變項數值大者在連續變項上得分較高;p、q 越接近 0.5 的時候 r_pb 才可能接近 1;二分變項編碼為 0/1 後,結果等於 Pearson r。
  • 相關的種類:簡單(積差)相關(兩變項)、多元(複)相關(多個預測變項與一個效標變項)、典型相關(多個變項與多個變項)。

📝 算例(取自 SS 練習題第 5 題的國語/數學資料):A~E 五位學生:國語 X = 4, 5, 6, 3, 2;數學 Y = 2, 3, 6, 4, 5。

  • X̄ = 4,Ȳ = 4;SSx = 0+1+4+1+4 = 10;SSy = 4+1+4+0+1 = 10。
  • SP = (0)(−2) + (1)(−1) + (2)(2) + (−1)(0) + (−2)(1) = 1。
  • 共變數 = SP/N = 1/5 = 0.2(若除以 n−1 則 0.25)。
  • r = SP/√(SSx·SSy) = 1/√(10×10) = 0.10。

W11 簡單直線迴歸

相關 vs 迴歸:相關看「有沒有關係」;迴歸用 X 預測 Y。X 稱預測變項(自變項),Y 稱效標變項(依變項)。只有一個預測變項 → 簡單直線迴歸。兩變項必須有顯著相關才可預測,無關聯的兩變項無法預測。

迴歸的種類:一個自變數 → 直線(簡單)迴歸、非直線迴歸;多個自變數 → 直線的複迴歸(多元迴歸)、非直線迴歸。

為什麼要用? 想知道能否用 X 解釋 Y,兩者關係是否密切到可以用一條線性方程式表示;求出一條經過這 n 個點的最適線性方程式,即可由 X 求 Y。

最小平方法:找一條直線,使各點到直線「平行縱軸(垂直於橫軸)的距離平方和最小」,即 Σ(Y − Ŷ)² = 最小。這條線叫最適合線(迴歸線)。

三種迴歸方程式

資料形式 方程式 說明
原始分數 Ŷ = a + bX 📝 b = SP/SSx = r·(Sy/Sx);a = Ȳ − b·X̄;實務預測用
離均差分數 ŷ = b·x(x = X − X̄、ŷ = Ŷ − Ȳ) 把原點移到平均數,截距 a 不見了,斜率不變
標準分數 Ẑy = β·Zx(簡單迴歸中 β = r) β = 標準分數化迴歸係數。多個預測變項要比較誰重要,要用 β(單位不同,原始 b 不能互比)

四個基本假設:①等分散性(變異數同質;不論預測變項 X 多大,在效標變項的估計標準誤都相等)②依變項(Y)成常態分配 ③預測關係是直線 ④不同 X 之下的 Y 互相獨立。

迴歸分析的用途:敘述(節目製作費 vs 收視率)、控制(控制價格以控制需求量)、預測(粗估某節目的收視率)。

📝 算例(承上國語/數學資料):b = SP/SSx = 1/10 = 0.1;a = 4 − 0.1×4 = 3.6 → Ŷ = 3.6 + 0.1X。國語 X = 5 → Ŷ = 4.1。β = r = 0.1。SSt = SSy = 10;SSreg = r²·SSt = 0.01×10 = 0.1;SSres = SSt − SSreg = 9.9(這組資料幾乎無法預測)。

📝 另一關係(SS 練習題第 4 題):令 b_yx 為 X 對 Y 的迴歸係數、b_xy 為 Y 對 X 的迴歸係數,則 r = ±√(b_yx · b_xy)(r 的符號與 b 相同)。

📝 算例(SS 練習題第 1、2 題,Z 分數資料):甲~戊五位的智力 Z 與學業 Z:乙 0.42/0.77、丙 −1.69/−1.92、丁 1.27/0.77、戊 ?/0.00,Z 總和必為 0,所以戊的智力 Z = 0.42。ΣZ智Z學 = 4.3865 → r = 4.3865/5 ≈ 0.877 → 標準分數迴歸 Ẑ學 = 0.877·Z智。若智力變異數 5.60、學業變異數 6.80 → Cov = r·Sx·Sy = 0.877×√(5.6×6.8) ≈ 5.41。

W12 多元迴歸與逐步迴歸

變異的拆解(SS 三公式)

  • 只知道 Y 的平均、不知道 X 時,最好的預測就是 Ȳ,誤差 = Y − Ȳ。平方加總 → SSt = Σ(Y − Ȳ)²(總離均差平方和、總變異)。
  • 有預測公式時預測 Ŷ,誤差 = Y − Ŷ。平方加總 → SSres = Σ(Y − Ŷ)²(殘差平方和、非被解釋變異)。迴歸係數就是讓 SSres 最小所求出的。
  • 猜 Ŷ 比猜 Ȳ 多進步的部分 = Ŷ − Ȳ。平方加總 → SSreg = Σ(Ŷ − Ȳ)²(迴歸離差平方和、被解釋變異)。
  • SSt = SSreg + SSres;R² = SSreg / SSt(決定係數:預測變項解釋了總變異的百分之幾)。簡單迴歸時 R² = r²。

多元(複)迴歸:預測變項 ≥ 2 個,Ŷ = a + b₁X₁ + b₂X₂ + … + bᵢXᵢ(a 截距、bᵢ 斜率);用於「用一組預測變項預測一個效標變項」。

  • 多元相關 R = Y 與 Ŷ 的積差相關。Ŷ 越接近 Y,預測越準。
  • 多元迴歸能解決:① 能否找出線性組合簡潔說明預測變項與效標的關係?② 關係強度?③ 整體是否顯著?④ 哪些預測變項最重要?原模式中的變項數能否減少而仍有足夠預測力?
  • b₁ 的意思:固定 X₂ 時,X₁ 對 Y 的迴歸係數(斜率)。
  • 三種形式:原始分數 Ŷ = a + b₁X₁ + b₂X₂;離均差 ŷ = b₁x₁ + b₂x₂(a = 0);標準分數 Ẑy = β₁Z₁ + β₂Z₂。
  • 📝 兩個預測變項的標準化係數:β₁ = (r_y1 − r_y2·r₁₂)/(1 − r₁₂²);β₂ = (r_y2 − r_y1·r₁₂)/(1 − r₁₂²);R² = β₁·r_y1 + β₂·r_y2。原始係數 bᵢ = βᵢ·(Sy/Sᵢ);a = Ȳ − Σ bᵢ·X̄ᵢ。

計算實例:Y = 大學入學考成績,X₁ = 高中學業成績,X₂ = 智力測驗。r_y1 = .643,r_y2 = .768,r₁₂ = .598。

  • β₁ = (.643 − .768×.598)/(1 − .598²) = .286;β₂ = .597 → 標準化迴歸式 Ẑy = .286Z₁ + .597Z₂。β₂ > β₁,所以智力測驗在預測上比高中學業成績重要。
  • R² = .286×.643 + .597×.768 = .6424(兩個預測變項解釋總變異的 64.24%);R = .8015(預測分數與實際分數相關)。
  • 轉回原始分數:Ŷ = 0.391X₁ + 1.061X₂ − 2.140。
  • 預測:某生 X₁ = 14、X₂ = 9 → Ŷ = 0.391×14 + 1.061×9 − 2.140 ≈ 12.88。
  • 注意:原始 b 不能互比(單位不同),不能因 1.061 > 0.391 就說 X₂ 較有預測力;要看標準化 β。

估計標準誤與預測區間:SEest = √(SSres / df) = √MSres。例:SSres = 33.4711,df = 7,MS = 4.7816 → SEest = √4.7816 ≈ 2.19。預測值 95% 區間 = Ŷ ± t(7, .025)×SEest = 12.88 ± 2.365×2.19 ≈ 7.70 ~ 18.06。

選預測變項的方法

  • 同時迴歸:所有預測變項一起投入,只估計係數,不負責篩選。
  • 所有可能迴歸法 vs 逐步選取法。
  • 順向選擇法:從候選變項中每次選一個能解釋效標總變異最多的變項:第一個選與 Y 積差相關最大者;之後選與 Y 的部分相關平方最大者。每進一個變項,計算 R² 增加多少,看新增變項是否有幫助。
  • 逐步迴歸法(Stepwise):順向選擇的改良(順向 + 反向淘汰)。每步只許一個變項進入,但已進入的變項會重新檢驗:若因新變項進入而不再顯著,就被剔除。用途:選擇或剔除變項、評估變項重要性。多用於探索性研究。SPSS 預設:進入 F 的顯著性機率 ≤ .05;移除 ≥ .10(SAS 常設兩者皆 0.15)。
  • 📝 共線性:預測變項彼此高度相關會讓係數不穩,SPSS 可用「共線性診斷」檢查。

SPSS 操作要點

  • 虛擬變數:間斷(類別)變項要轉成 0/1 才能投入迴歸;個數 = 水準數 − 1,沒編碼的那一組是參照組。
  • 二分(性別):1 個(1 = 女、0 = 男)。
  • 三分(家庭狀況):2 個:單親(1,0)、他人照顧(0,1)、雙親(0,0)。
  • 四分(北、中、南、東):3 個:北(1,0,0)、中(0,1,0)、南(0,0,1)、東(0,0,0)。
  • 轉換:轉換 → 重新編碼成同一/不同變數。迴歸:分析 → 迴歸 → 線性;效標變項放「依變數」,預測變項放「自變數」;方法可選;統計量可勾選估計值、模式適合度(列出進入或刪除的變項與 R、R²、調整後 R²、估計標準誤、變異數分析摘要表)、共線性診斷。
  • 讀報表:模式摘要(R、R²)、ANOVA(P < .01 → 模式顯著)、係數表(B = 原始迴歸係數、Beta = 標準化係數、各係數的 t 檢定)。
  • 講義例:以「性別、壓力懼怕、情緒擔憂、考試焦慮、課堂焦慮、學習信心、有用性、成功態度、探究動機、工作投入、自我投入」共 11 個預測變項預測「數學成就」(1 個依變項,屬多元迴歸)。逐步法最後模型:數學成就 = −4.522 + .309×工作投入 + .382×成功態度 − .401×自我投入 + 3.080×學生性別 − .344×壓力懼怕 + .610×課堂焦慮 + .222×學習信心 + .249×有用性。📝 係數 3.080 表示:性別編碼 1 = 女生時,在其他變項相同下,女生數學成就比男生高 3.08 分。

W13 卡方考驗(χ²)

用途:前面各章多為連續變項;教育心理多半是類別(名義、次序)資料,此時用卡方。問卷調查最常用。回答的問題:從樣本觀察到的類別資料,和理論或母群體的類別資料有沒有顯著差異? 由 Pearson 導出。

  • 定義:自常態母體抽 X 轉成 Z,χ² = ΣZ²(df = n);用樣本變異數時 df = n − 1。
  • 卡方分配也可用於母體變異數的區間估計與假設考驗。
  • 進行卡方考驗只需對母體做簡單假設,不需知道母體參數或分配 → 有人視為無母數統計。
  • 類別資料產生方式:原發性(性別本質就是類別)、操弄性(實驗操弄的分類結果)、虛擬化(由連續變項轉成類別)。

核心公式:χ² = Σ (O − E)² / E(O = 觀察次數,E = 期望次數)。O 與 E 差距越大 → χ² 越大 → 越可能落入右尾拒絕區 → 拒絕 H₀。卡方考驗通常只做單尾(右尾)。 注意事項:①只適用類別資料 ②各格期望次數最好 ≥ 5(至少 80% 的格子 ≥ 5),否則可將格子合併 ③理論次數太小要校正 ④兩個獨立卡方值相加仍是卡方,自由度也相加。

📝 5% 臨界值速查(右尾):df = 1 → 3.841;2 → 5.991;3 → 7.815;4 → 9.488;5 → 11.070。(1% 水準:df = 1 → 6.635;2 → 9.210。)

常考觀念陷阱(來自成果驗收題)

  1. 信賴區間越大 → 信心水準越高,但精確度越低。
  2. t 檢定要求母體常態;違反時補救是增加樣本數(中央極限定理)。
  3. 中央極限定理的前提不需要母體是常態。
  4. 常態分配:平均 = 中位數 = 眾數;±3σ 之外只有約 0.3%(「±5σ 外有 1%」是錯誤敘述)。
  5. 相關係數看絕對值判斷強弱;不是斜率;不等於因果。
  6. R² = SSreg / SSt;SSt = SSreg + SSres。
  7. 虛擬變數個數 = 水準數 − 1。
  8. 卡方的期望次數太小(< 5)要合併或校正。
  9. 變異數的區間估計用卡方,不能「± 誤差」。
  10. 迴歸中的 β 是「標準化迴歸係數」,不是 W8 的「型 II 錯誤」。
